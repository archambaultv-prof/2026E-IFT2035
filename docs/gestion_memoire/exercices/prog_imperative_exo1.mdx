# Exercice 1 — Pile, tas et zone statique

## Partie A — Classifier les variables

Soit le programme C suivant :

```c
#include <stdio.h>
#include <stdlib.h>

int compteur = 0;

void incrementer(void) {
    static int appels = 0;
    appels++;
    compteur++;
    printf("appel %d, compteur = %d\n", appels, compteur);
}

int* creer_tableau(int n) {
    int* t = malloc(n * sizeof(int));
    for (int i = 0; i < n; i++) {
        t[i] = i * i;
    }
    return t;
}

int main(void) {
    int x = 10;
    int* tab = creer_tableau(x);
    incrementer();
    incrementer();
    free(tab);
    return 0;
}
```

elle est stockée (**zone statique**, **pile**, ou **tas**) et justifier :

| `x` (dans `main`) | ? | |
| `tab` (le pointeur, dans `main`) | ? | |
| `*tab` (le bloc pointé, i.e. le contenu) | ? | |
| `t` (le pointeur, dans `creer_tableau`) | ? | |
| `n` (paramètre de `creer_tableau`) | ? | |
