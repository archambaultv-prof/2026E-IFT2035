# Concepts des langages de programmation

Bienvenue sur le site du cours Concepts des langages de programmation (IFT
2035) de l'[Université de Montreal](https://www.umontreal.ca/). Ce site
présente le contenu du cours dispensé par le professeur [Vincent
Archambault-Bouffard](https://github.com/archambaultv-prof) durant la session
d'été 2026.

## Plateforme StudiUM

Ce site web complète mais ne remplace pas
[StudiUM](https://studium.umontreal.ca/). Les étudiants doivent continuer à
consulter régulièrement StudiUM pour les annonces officielles et les
informations administratives.
