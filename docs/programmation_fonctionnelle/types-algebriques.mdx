# Types algébriques

## Déclarer un type avec `data`

En Haskell, on déclare un nouveau type avec le mot-clé `data` :

```
data NomDuType = Constructeur1 | Constructeur2 | ...
```

Chaque **constructeur** est une façon de construire une valeur de ce type.
Par exemple, `Bool` est défini ainsi dans la bibliothèque standard :

```haskell
data Bool = False | True
```

`False` et `True` sont deux constructeurs sans argument. Un `Bool` est soit
`False`, soit `True` — rien d'autre.

On peut définir ses propres types de la même façon :

```haskell
-- Les jours de la semaine
data Jour = Lundi | Mardi | Mercredi | Jeudi | Vendredi | Samedi | Dimanche

-- Les saisons
data Saison = Printemps | Été | Automne | Hiver
```

## Constructeurs avec arguments

Les constructeurs peuvent aussi **prendre des arguments** :

```haskell
-- Une forme géométrique : soit un cercle (avec son rayon),
-- soit un rectangle (avec sa largeur et sa hauteur)
data Forme = Cercle Double | Rectangle Double Double
```

```haskell
ghci> :type Cercle
Cercle :: Double -> Forme

ghci> :type Rectangle
Rectangle :: Double -> Double -> Forme

ghci> Cercle 5.0
Cercle 5.0

ghci> Rectangle 3.0 4.0
Rectangle 3.0 4.0
```

Un constructeur avec arguments se comporte comme une **fonction** : on lui
passe ses arguments et on obtient une valeur du type déclaré.

:::info[Exemple]
Un type pour représenter le résultat d'une division (qui peut échouer si le
diviseur est zéro) :

```haskell
data RésultatDiv = Succès Double | ErreurDivParZéro

diviser :: Double -> Double -> RésultatDiv
diviser _ 0 = ErreurDivParZéro
diviser x y = Succès (x / y)

ghci> diviser 10 2
Succès 5.0
ghci> diviser 10 0
ErreurDivParZéro
```
:::

## Types polymorphes

Un type peut avoir des **paramètres de type** (variables de type), ce qui le
rend générique :

```haskell
data Maybe a = Nothing | Just a
```

`Maybe a` représente une valeur optionnelle de type `a` :
- `Nothing` — aucune valeur
- `Just x` — la valeur `x`

```haskell
ghci> :type Nothing
Nothing :: Maybe a

ghci> :type Just
Just :: a -> Maybe a

ghci> Just 42
Just 42

ghci> Just "bonjour"
Just "bonjour"
```

`Maybe` est le type standard de Haskell pour remplacer les valeurs `null` ou
les exceptions dans les cas simples d'absence de valeur.

:::tip[Syntaxe Haskell — `data`]
La déclaration `data` crée à la fois le **type** et ses **constructeurs**.
Les constructeurs commencent toujours par une **majuscule** ; les variables de
type commencent par une **minuscule**.

```haskell
data Couleur  = Rouge | Vert | Bleu        -- type énumération
data Point    = Point Double Double         -- un seul constructeur avec champs
data Maybe a  = Nothing | Just a           -- type polymorphe
data Either a b = Left a | Right b         -- deux alternatives typées
```

`Either a b` est utile pour représenter un résultat qui peut être de deux
natures différentes — par exemple une valeur (`Right`) ou un message d'erreur
(`Left`).
:::

## Les listes — un type algébrique récursif

La liste en Haskell est elle-même un type algébrique, défini (conceptuellement)
ainsi :

```haskell
data [a] = []       -- liste vide
         | a : [a]  -- tête de type a, suivie d'une liste de a
```

- `[]` est le constructeur de la liste vide.
- `(:)` (prononcé *cons*) est le constructeur qui ajoute un élément en tête.

C'est un type **récursif** : la définition de `[a]` fait référence à `[a]`
elle-même. Cela permet de représenter des listes de n'importe quelle longueur.

```haskell
ghci> 1 : 2 : 3 : []
[1, 2, 3]

ghci> :type (:)
(:) :: a -> [a] -> [a]
```

La notation `[1, 2, 3]` est un raccourci syntaxique pour `1 : 2 : 3 : []`.
